# MealHub

Веб-система для управления питанием: меню, заказы, выдача, учёт ингредиентов и отчёты. В коде есть интерфейсы пользователя, повара и администратора. Сервер написан на Django; по умолчанию используется SQLite.

Это исходный код прототипа, а не готовая конфигурация для промышленного размещения. Для просмотра без установки сервера есть [статическое демо](https://axilium1749.github.io/demos/mealhub/). Демо использует вымышленные данные и не подключено к этому серверу.

## Локальный запуск

Нужен Python 3.12 или новее.

```bash
python -m venv .venv
```

Активируйте окружение (`.venv\Scripts\activate` в PowerShell или `source .venv/bin/activate` в Linux/macOS), затем:

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py loaddata allergens.json
python manage.py createsuperuser
python manage.py runserver
```

Локальный адрес: `http://127.0.0.1:8000/`. Для входа используйте созданного суперпользователя. Пример конфигурации находится в `.env.example`; Django читает переменные окружения процесса, файл `.env` сам по себе не загружается.

## Конфигурация

- `DJANGO_SECRET_KEY` — постоянный секретный ключ для размещённого сервера. Без него при локальном запуске генерируется временный ключ.
- `DJANGO_DEBUG` — `1` для локальной разработки, `0` при размещении.
- `DJANGO_ALLOWED_HOSTS` — список разрешённых доменов через запятую; по умолчанию `127.0.0.1,localhost`.

Перед размещением настройте HTTPS, статику, резервное копирование базы и отдельный постоянный секретный ключ. Не публикуйте рабочую базу данных и данные пользователей.
